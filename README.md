# IWD-Project
 A digital solution designed to streamline hostel mess management. The layout is clean and modern, featuring a professional color palette of teal, white, and dark green. The hero section prominently features the headline "Digital Mess, Smart Solutions," followed by a brief description highlighting features like leave applications, meal charge calculations, and 100% transparency. Two prominent call-to-action buttons, "Student Portal" and "Admin login," are placed centrally to guide users to their respective dashboards.
On the right side of the screen, there is a "Today's Menu" card that adds a touch of humor to the development process, listing satirical dishes such as "Paneer mosquito Masala," "Rukha Sukha Roti," and "Sara huaa Salad." The navigation bar at the top includes links for Home, About, Menu, Features, and a "Visit GECK" option, alongside a "Register Now" button. Technical details in the browser's address bar indicate that the site is being run on a local server via VS Code Live Preview, confirming that the project is currently in the active development and testing phase.
